# Movie Rental Store

> Work-in-progress movie rental app built while transitioning to React/TypeScript.

🔗 [Live demo](https://movie-rental-store-eta.vercel.app/)

## Tech Stack

- React + TypeScript
- Zustand (client state)
- TanStack Query (server state)
- React Router v7
- Tailwind CSS
